# invoice-cn · 增值税发票开具工具

零依赖（原生 HTML/CSS/JS）的电子发票开具演示：编辑买卖方信息与商品明细，实时计算税额、生成大写金额，按真实票样预览并支持打印。

## 功能

- **购销双方信息**：名称、纳税人识别号（15-20 位格式校验）、地址电话、开户行账号
- **多行商品明细**：名称 / 规格 / 单位 / 数量 / 不含税单价 / 税率（13% / 9% / 6% / 1% / 免税），动态增删行
- **分位精度计算**：全程以"分"为单位的整数运算，杜绝浮点误差；税额四舍五入到分
- **人民币大写金额**：完整实现拾佰仟 / 万亿分组 / 零的省略与补位规则（如 ¥1002003.05 → 壹佰万零贰仟零叁元零伍分）
- **真实票样预览**：宋体版式、红色双线边框、购买方/销售方竖排表头、空白行补齐
- **打印优化**：`@media print` 隐藏编辑区，只输出发票票面

## 计算规则

```
金额（不含税）= round(单价 × 数量, 分)
税额         = round(金额 × 税率, 分)
价税合计     = Σ金额 + Σ税额        （分位累加，最后转元）
```

## 大写金额转换规则

- 整数部分按 4 位一组（万 / 亿 / 兆）分组处理
- 组内连续的零只读一个"零"，末尾零省略
- 低位组不足千位时高位组后补"零"（壹亿零伍万）
- 无角分时加"整"，有分无角时加"零"（壹拾元零伍分）

## 文件结构

```
C21-invoice-cn/
├── index.html   # 左编辑区 + 右票样预览（打印时只留票样）
├── styles.css   # 票样版式（红色双线边框）+ @media print
├── invoice.js   # InvoiceEngine：分位计算 / 大写转换 / 校验
└── app.js       # 明细行编辑、预览渲染、打印
```

## 本地运行

直接用浏览器打开 `index.html` 即可。可修改明细验证大写金额的边界情况（如 10000、10000000、0.05）。
